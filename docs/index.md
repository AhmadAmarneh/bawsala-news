# Bawsala News - Hybrid News Aggregator and CMS

## Overview
Bawsala News is a "Hybrid News Aggregator and CMS" built for a university graduation project. 

## System Architecture
- **Framework**: Next.js 14+ (App Router)
- **Backend & Database**: Supabase (PostgreSQL)
- **Styling & UI**: Tailwind CSS, shadcn/ui, lucide-react
- **RSS Parsing**: rss-parser

## Database Schema (Supabase)
The database contains the following tables:
1. `users`: id, email, role (enum: admin, journalist, reader).
2. `sources`: id, name, rss_url, is_active.
3. `categories`: id, name.
4. `articles`: id, title, content, type (enum: exclusive, aggregated), author_id (FK to users), source_id (FK to sources), original_url, category_id, published_at.
5. `saved_articles`: id, user_id, article_id.

## Folder Structure
- `/app/(public)`: Public-facing frontend, dynamic timeline, homepage, and article reading page.
- `/app/(dashboard)`: CMS dashboard for admins and journalists.
- `/app/api/cron/fetch-news/route.ts`: API route for RSS fetching.
- `/docs`: Project documentation and architecture details.

## Setup Instructions
1. Run `npm install` to install dependencies.
2. Initialize Supabase locally using `npx supabase init`.
3. Start Supabase locally with `npx supabase start` (Docker required).
4. Apply migrations to set up the DB and Storage.
5. Run the database seed script: `supabase/seed.sql` to populate mock data (Users, Categories, Sources, Articles).
6. Run the development server with `npm run dev`.

## Features

### Authentication & RBAC (Role-Based Access Control)
- **Supabase Auth**: Implemented standard Email/Password authentication via `@supabase/ssr`.
- **User Profile Sync**: A PostgreSQL trigger automatically copies new users from the `auth.users` schema into our public `users` table upon registration, assigning them a default `reader` role.
- **Next.js Middleware (`middleware.ts`)**: Secures the CMS dashboard routes.
  - Queries the current session via cookies.
  - Checks the synced `users` table for the user's role.
  - Only allows users with an `admin` or `journalist` role to access `/dashboard`. Other users are redirected back to the homepage.
  - Authenticated users attempting to view `/login` or `/register` are redirected to the dashboard.
### Admin Sources Management (`/app/dashboard/sources`)
- **RBAC Enforcement**: Protected via `proxy.ts` (Next.js Middleware). Only users with the explicit `admin` role can access this route; journalists are automatically redirected to the dashboard home.
- **UI & Capabilities**: 
  - Uses `shadcn/ui` components (`Table`, `Dialog`, `Switch`) for a clean, data-dense interface.
  - Admins can add new external RSS sources (URLs are strictly validated via Zod).
  - Admins can toggle the `is_active` status of a source to pause or resume fetching from that specific site during the next cron job.
  - Admins can delete sources entirely (with a safe confirmation dialog).

### Saved Articles (Bookmarks)
- **Bookmark Button Component**: A reusable interactive Client Component using `lucide-react` icons that allows readers to save or unsave articles. It updates optimistically for immediate visual feedback.
- **Server Actions**: Saving and unsaving logic is handled securely via Next.js Server Actions (`/app/actions/save-article.ts`), ensuring only authenticated users can interact with the `saved_articles` table. Unauthenticated clicks trigger a `sonner` toast notification.
- **Saved Articles Page (`/app/(public)/saved`)**: A dedicated route that queries the `saved_articles` table (joined with `articles`) to display the user's bookmarked news in the standard grid layout.
- **Homepage Timeline (`/app/(public)/page.tsx`)**: Fetches a mixed feed of both `exclusive` (local) and `aggregated` (external) articles directly from Supabase, ordered by `published_at` descending.
- **UI Distinctions**: The timeline uses conditional rendering to attach "Local/Exclusive" badges (blue) or "Via [Source]" badges (gray) with `ExternalLink` icons.
- **Article Page (`/app/(public)/article/[id]/page.tsx`)**: A distraction-free reading experience for exclusive articles. 
- **Typography Parsing**: The HTML generated by the CMS Tiptap editor is passed into `dangerouslySetInnerHTML`. It relies on the `@tailwindcss/typography` plugin using the `.prose` class to automatically style headers, bold text, lists, and images beautifully without writing custom CSS.
### Rich Text Editor (CMS)
- **Library**: `TipTap` (with `@tiptap/react`, `@tiptap/starter-kit`, `@tiptap/extension-underline`, `@tiptap/extension-image`).
- **Styling**: Uses `@tailwindcss/typography` (`.prose`) and `shadcn/ui` buttons for a clean, premium interface.
- **Image Upload**: Integrated directly with **Supabase Storage**. When an image is uploaded in the editor, it is stored in the `article-images` public bucket. The returned public URL is then embedded directly into the article content.
- **Functionality**: Supports Bold, Italic, Underline, Headings (H1/H2), Bullet Lists, Ordered Lists, and inline Images. The form wraps this editor to also capture the article's `title`, `category_id`, and `type`.
